# Referensi visual

Acuan **gaya**, bukan untuk ditiru persis (karakter dan brand Pidu milik pembuat UI kit tersebut).

- `pidu-1-cover.png`, `pidu-2-layar-utama.png`, `pidu-3-semua-layar.png`: UI kit Pidu. Yang ditiru: header hijau bulat, tombol chunky dengan bayangan padat, kartu putih bulat, **tile/stiker pastel warna-warni** (kuning, pink, ungu, oranye) di dalam kartu, tombol oranye sebagai aksen, maskot besar yang "keluar" dari header, angka besar tebal.
- Yang tidak ditiru: maskot bunglon, ikon bahasa, sistem level yang mengunci konten, dan misi harian.
- Sejak PRD 1.4, **jalur** (layar Jalur dari data proyek nyata) dan **streak mingguan** (tampilan, tanpa bonus poin) ikut dipakai sebagai gaya. Aturannya ada di PRD bagian 17.
- `../image.png`, `../image1.png`: cover proposal hackathon (bukan acuan UI app).
